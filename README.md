# Jett Screenshot Style

Die hochgeladene, bereits von dir bearbeitete index.html wurde beibehalten.
Dazu:
- keine Profil-Box / kein Glas-Kasten
- Name und Social-Icons direkt über dem Video
- weiße Jett-artige Icons mit Glow
- dezente Buchstabenanimation für den Namen
- vorhandenes Video und vorhandene Musik bleiben eingebunden

Die zusätzlichen Dateien style.css und script.js gehören in denselben Ordner wie index.html.
